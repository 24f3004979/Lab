### Setup
1. Install uv
2. run `uv sync' to fetch all dependency
3. Initiate kernel `uv run ipython kernel install --user --name=ml-lab-kernel --display-name="Python (ML Lab)"` Initiates a kernel and connection with backend
4. Check out with your fav editor

[!Note]
Current uv sync would also fetch a default hosting with jupyter-lab web-interface for the projecct so you can also switch for your own setup rather then using it
